# KSPlayer

An FFmpeg-based player for iPhone and iPad: MKV, HEVC, HDR and Dolby Vision,
ASS and PGS subtitles, and MPEG-TS live streams AVPlayer cannot play.

## Category

**Player** — `players/ksplayer`. Device-wide.

## Platforms

iOS (tvOS later).

## Licence

KSPlayer is GPL unless its LGPL licence is bought. Phase 8 decides that before
anything is built.

## Status

Manifest only, with no profile, so the app never picks it. Planned for Phase 8,
as an Expo module in this package.
