# OneDrive

Video files from OneDrive.

## Category

**Source** — `sources/onedrive`. Its files show on the Videos tab. Its
connections belong to the account. Keeping the account's backup in OneDrive is
another plugin, `sync/onedrive`.

## Brings

Files.

## Connection

No fields yet: signing in is a Microsoft sign-in (PKCE), which arrives with
the implementation.

## Status

Manifest only. No media role yet, so no capability is declared.
