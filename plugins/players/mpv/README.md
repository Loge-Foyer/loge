# mpv

The mpv engine — MPVKit on iPhone and iPad, libmpv on Android — for nearly any
file: MKV, HEVC, DTS, TrueHD, with libass subtitles.

## Category

**Player** — `players/mpv`. Device-wide.

## Platforms

iOS and Android.

## Status

Manifest only, with no profile, so the app never picks it. Planned for Phase 8,
as an Expo module in this package, built from LGPL releases.
