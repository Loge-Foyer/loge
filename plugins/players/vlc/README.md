# VLC

VLC's engine — VLCKit on iPhone and iPad, libVLC on Android — for nearly
anything, streams included.

## Category

**Player** — `players/vlc`. Device-wide.

## Platforms

iOS and Android. There is no VLC for the web.

## Status

Manifest only, with no profile, so the app never picks it. Planned for Phase 8
(LGPL).
