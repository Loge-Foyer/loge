# Google Drive (backups)

Keeps the account's encrypted backup file in Google Drive, in a visible
"Streaming Center" folder, saved after changes and opened on another device.

## Category

**Sync**, with a `backup` block — `sync/google-drive`. Device-wide. Browsing
Drive's files is another plugin, `sources/google-drive`, with its own sign-in.

## Platforms

iOS, Android and the web.

## Status

Manifest only. The backup role — a Google sign-in (PKCE), and conditional
writes — is planned after the players (see Phase 9's list).
