# OneDrive (backups)

Keeps the account's encrypted backup file in OneDrive's app folder, saved after
changes and opened on another device.

## Category

**Sync**, with a `backup` block — `sync/onedrive`. Device-wide. Browsing
OneDrive's files is another plugin, `sources/onedrive`.

## Platforms

iOS, Android and the web.

## Status

Manifest only. The backup role is planned after the players (see Phase 9's
list).
